# DUVARLA DERİN SOHBET SİMÜLATÖRÜ

## Duvar Sizi Dinliyor. Siz de Onu Dinleyin.

Bu proje, insanlık tarihinin en derin felsefi sorularına cevap arayan bir simülatördür. 
Cevaplar yoktur. Sadece duvar vardır. Ve sessizlik.

### Özellikler

- Duvar gerçekten cevap vermez.
- Siz yine de konuşursunuz.
- Sonunda herkes mutlu olur. (Belki.)

### Kullanım

```bash
python duvar_sohbeti.py
```

Enter'a basın ve duvarla derinlemesine sohbet edin.

### Neden?

Çünkü bazen en iyi arkadaş, cevap vermeyen bir duvardır. 
Bu kod, o anı ölümsüzleştirir.
